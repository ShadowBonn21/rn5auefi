# UEFI для Redmi Note 5A Prime (ugg / MSM8940) — что здесь есть и что дальше

## TL;DR

1. **Готового UEFI для этого телефона не существует.** Renegade/edk2-msm начинается с
   MSM8998 (Snapdragon 835). Для MSM8937/8940 порта нет ни в апстриме, ни в форках.
2. **Портировать можно, но это исследовательский проект, а не «скачать и прошить»:**
   на этих SoC у edk2-msm нет *ни одного* готового драйвера (eMMC, USB, PMIC, клоки) —
   они поставляются закрытыми бинарями под каждый SoC, а для msm8937 их не собрал никто.
3. **Первый и главный вопрос — умеет ли LK (aboot) этого телефона входить в AArch64.**
   Это проверяется за 2 минуты и на 100% безопасно: `tools/probe.ps1` (fastboot boot,
   на флеш ничего не пишется). Ответ определит всё остальное.
4. **Если цель — «запускать любые системы»**, то честный путь для этого телефона —
   Linux (Debian/Ubuntu/Alpine/postmarketOS) с custom-ядром и своим initramfs, без UEFI.
   Windows on ARM здесь не поедет никогда: нет ACPI/драйверов.

## Что делать прямо сейчас

```powershell
# 1) телефон в Android, USB-отладка включена:
powershell -ExecutionPolicy Bypass -File tools\collect-dumps.ps1

# 2) проба AArch64 (телефон сам уйдёт в fastboot и вернётся):
powershell -ExecutionPolicy Bypass -File tools\probe.ps1
```

Результат пробы:

* **Экран мигает красный ↔ циан** → LK входит в AArch64, framebuffer верен.
  Можно идти по плану G1…G5, у порта есть шанс.
* **Чёрный экран / логотип / перезагрузка** → три варианта: нужен DTB
  (`--dtb build\stock.dtb`), неверный адрес FB, либо LK вообще 32-битный.
  Тогда следующий шаг — 32-битная ветка (EDK2 ARM) или отказ от UEFI в пользу Linux-пути.

## Чего я не могу сделать в этой среде

* **Собрать и протестировать прошивку.** Нет aarch64-тулчейна, нет WSL-дистрибутива,
  свободно 4.9 ГБ (нужно 6–8 ГБ), и главное — телефон не подключён.
* **Написать закрытые драйверы SoC «на глаз».** Драйвер eMMC (SDCC/SDHCI) и USB (dwc3)
  пишутся итеративно, с живым устройством и, желательно, с UART — иначе отладка слепая.
* Поэтому формат работы: я пишу код и процедуры, вы выполняете шаги на телефоне и
  присылаете вывод (adb/fastboot/дампы) — я правлю код.

## Что мне нужно от вас (по приоритету)

1. Вывод `tools\collect-dumps.ps1` (папка `dump\<серийник>\`) — целиком.
2. Результат `tools\probe.ps1` — словами: что было на экране.
3. Стоковый `boot.img` и раздел `aboot`/`bootloader` (команды в `docs/03-dumps.md`).
4. Разблокирован ли загрузчик (Mi Unlock) — от этого зависит, можно ли вообще
   запускать свои образы.
